# Templates e Conhecimento Organizacional — Brain (Project Brain OS 2.0)

- `organization/`: visão, princípios de engenharia e ADRs globais (`project_id = '__org__'`).
- `projects/`: documentação versionada por projeto quando declarada em `.project-brain.json`.
- `templates/`: modelos oficiais de `BusinessRule`, `ADR` e `Requirement`.
- `policies/`: políticas OPA e padrões de segurança corporativos.
